# 会话查看器：离线数学公式排版

在 Chromium 系浏览器中打开包根的 [viewer.html](../viewer.html)，选择本地会话文件夹。已有页面需要刷新或重新打开，才能加载更新后的脚本。查看器只读会话，不会修改原来的提示词或消息。选目录后运行才新生成的会话图片，会在进入视口时通过已授权目录句柄按精确 `media/...` 路径读取，不依赖初次扫描清单，也不会预读所有图片。新消息仍需点击查看器的“刷新”或重新选择会话读取；本次改动不是自动监听。旧版页面误报“未找到图片”时，先刷新浏览器加载新脚本，再选择会话目录。

## 支持的公式语法

| 类型 | 分隔符示例 |
| --- | --- |
| 行内公式 | `$x_i^2+\alpha$` |
| 行内公式 | `\(\rho=2\cos\varphi\)` |
| 独立公式 | `$$\int_0^1 x\,dx$$` |
| 独立公式 | `\[x^2+y^2+(z-1)^2=1\]` |

独立公式支持多行正文。公式内容先从 Markdown 中保护出来，再排版，因此下标、星号和多行对齐不会被误当作 Markdown。正文、展开后的思考和工具文字都使用同一套解析规则。

行内代码与代码围栏保持源码，包括绘图提示词中围起来的书稿上下文；这些区域中的公式不会排版。围栏支持三枚及以上反引号或波浪号，并按类型与长度匹配，能够保留上下文内嵌的代码块。转义美元符号、未配对的 `\)`／`\]` 以及无法解析的公式会保留原文。没有配对的结束符不会被猜测补全或静默删除。

## 离线资源

排版使用固定的 KaTeX 0.18.2，不需要 CDN、包管理器或运行时下载。移动或分发查看器时，必须一起保留：

- [本地数学解析脚本](../scripts/viewer_math.js)。
- [KaTeX 脚本](../vendor/katex-0.18.2/katex.min.js)、[样式](../vendor/katex-0.18.2/katex.min.css)及相邻的 `fonts/` 目录。

只复制 HTML 不包含公式资源。脚本未加载时保留可读文字；正确的源码 Skill 导出会自动包含这些资源。宽公式在消息内部滚动，字体文件也从本地加载。

KaTeX 支持常见 LaTeX 数学语法，并不执行 TeX 程序。渲染固定使用 `trust: false`；异常公式由 `throwOnError: true` 与捕获逻辑保留完整带分隔符原文，不中断其他消息。公式缓存有上限，折叠的思考和工具内容仍按原查看器规则在展开后排版。

官方 npm 归档、版本、许可和校验值见 [KaTeX 来源记录](katex-upstream.json)；逐文件 SHA-256、大小与原路径见 [资源清单](../vendor/katex-0.18.2/RESOURCE-MANIFEST.json)，原许可保存在 [LICENSE](../vendor/katex-0.18.2/LICENSE)。
